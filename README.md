# 404围棋网

一个围棋主题的网站，提供清晰的导航和优雅的用户界面。

## 功能特点

- **可收起的侧边栏菜单**：左侧菜单栏可以通过点击按钮收起/展开
- **响应式设计**：自适应不同屏幕尺寸
- **现代化UI**：使用渐变色和卡片式设计
- **流畅动画**：平滑的过渡效果和交互体验

## 文件结构

```
.

├── styles.css      # 样式表
├── script.js       # JavaScript交互逻辑

```

## 使用方法

直接在浏览器中打开 `index.html` 文件即可查看网站。

或者使用本地服务器：

```bash
# 使用Python
python3 -m http.server 8000

# 使用Node.js
npx serve
```

然后在浏览器中访问 `http://localhost:8000`

## 特性说明

### 侧边栏收起功能
- 点击侧边栏右上角的菜单按钮（☰）可以收起侧边栏
- 侧边栏收起后，会在主内容区左上角显示一个菜单按钮
- 点击该按钮可以重新展开侧边栏
- 侧边栏的状态会保存在浏览器的 localStorage 中

### 响应式设计
- 在桌面设备上，侧边栏默认展开
- 在移动设备上，点击导航链接后会自动收起侧边栏
- 布局会根据屏幕尺寸自动调整
